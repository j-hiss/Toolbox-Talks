# customer-yards evidence

Sources fetched by this writer (WebFetch):
- 3944 = OSHA 3944-04 (2018), "Safety Practices Once Tractor Trailer Drivers Arrive at a Destination", https://www.osha.gov/sites/default/files/publications/OSHA3944.pdf (QuickCard-style; fetched twice, verbatim quotes below).
- LU = OSHA Trucking Industry, Loading and Unloading, https://www.osha.gov/trucking-industry/loading-unloading (summarizes the 1999-10-28 interpretation).
- TIB = OSHA TIB 00-07-31, https://www.osha.gov/sites/default/files/publications/tib20000731.pdf.
- 1910.178(l)(1)(i): the osha.gov standardnumber page could not be fetched (tool provenance block); text verified on eCFR, https://www.ecfr.gov/current/title-29/subtitle-B/chapter-XVII/part-1910/subpart-N/section-1910.178. Fact-checker: please confirm on osha.gov.

No OSHA standard covers "arriving at a customer's yard" as such. Truck operation on public highways is DOT/FMCSA territory; OSHA has authority over off-highway loading and unloading (LU). The talk is built on OSHA guidance (3944, LU, TIB) plus the host-employer forklift-training interpretation.
