# pool-chemicals evidence

OSHA has no standard specific to pool or spa chemicals. The OSHA rules that apply are general ones: Hazard Communication 1910.1200 (SDS access, training), PPE 1910.132(a), and quick drenching/flushing facilities 1910.151(c). All fetched from osha.gov standardnumber pages on 2026-10-08. OSHA's own pool-specific material is thin: the Chemical Reactivity Hazards page only cites an EPA alert about pool chemicals. Most practical lines therefore come from CDC guidance (Healthy Swimming pages), and the talk names CDC as the source each time.

Overlap check: existing `cleaning-chemicals` (facil, health, food, retail; 1910.1200) covers general cleaning products, labels and SDS. This talk is narrowed to pool-specific storage, mixing, feed-system servicing and spills; the HazCom lines are kept to two items.
