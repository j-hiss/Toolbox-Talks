# equipment-rops — evidence

Pages fetched 2026-10-07 with WebFetch (short exact quotes, each under 125 chars, plus summaries). "exact" = returned as a verbatim quote.

Corrections to the assignment's paragraph numbers:
- 1926.600(a)(3) is not about getting on/off; it covers blocking raised equipment, lowering blades/buckets, controls neutral, parking brake and chocks. Used for the parking section.
- 1926.602(a)(2) only requires seat belts to be **provided** (employer duty); it does not say "wear". The "wear it" line comes from OSHA eTool guidance.
- 1926.1001 is performance criteria only (scope list in (a)); labeling and remounting are in 1926.1000(d)-(e), not 1926.1001.
- No OSHA construction standard covers mounting/dismounting equipment (1926.602 has no such paragraph; eTool and Struck-By instructor guide have nothing on it). The getting-on/off lines come from the NIOSH skid-steer Alert, so that section is headed "Skid steers".

Dropped / not used:
- "Don't jump clear in a rollover": common advice, but not on any page fetched. Dropped.
- "Never run a machine with the ROPS removed": not stated as such; 1926.1000(d) covers remounting only. Dropped.
- 1926.1000(f) (older machines meeting 1972 state/federal requirements are deemed to comply): too detailed, and uses "compliance" wording.
