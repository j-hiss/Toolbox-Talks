Dropped / not used:
- "Never lift over people": 1910.179(n)(3)(vi) says the operator must "avoid" carrying loads over people, so the talk says "avoids" and pairs it with 1910.184(c)(9) (keep clear of suspended loads). It does not say "never".
- Hook safety latches: no latch requirement for hooks in 1910.179 or 1910.184 (the only "latch" is the controller off-position latch, (g)(3)(ii)). Left out.
- Standard hand signals: 1910.179 has no hand-signal chart or signal-person rule (unlike the construction crane standard). Only the warning-signal rule (n)(3)(xi) was used.
- "Trained" operators: the standard says "designated" (employer selects as qualified); no training wording was found, so the talk says "designated as qualified".

Paragraph corrections: 1910.179(j)(1) has (i) initial and (ii)(a)/(b) frequent/periodic; there is no (j)(1)(iii). (n)(3)(ix) (one qualified person in charge) applies only when two or more cranes lift one load; not used.
