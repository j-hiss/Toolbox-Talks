Dropped for lack of an OSHA/NIOSH source (all found only in Washington State L&I TIRES materials archived on CDC Stacks, which are a state agency's publications):
- "Face the vehicle" when climbing (WA L&I, stacks.cdc.gov/view/cdc/200224 and 221422).
- Check steps and ground for ice, water, mud or debris before stepping down (WA L&I "Fatal fall", stacks.cdc.gov/view/cdc/200324).
- Wear slip-resistant footwear with good traction (WA L&I).
- Keep grab handles and steps clean and securely mounted; install grab handles near doors (WA L&I).
- Statistic "nearly one quarter of truck driver injuries with days away from work came from mounting/dismounting" (Garg et al., J Ergon 2014, in NIOSH's Stacks collection): a journal study, not an OSHA/NIOSH figure; left out.
