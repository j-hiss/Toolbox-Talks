# tractor-rops evidence

Paragraph notes:
- The seatbelt requirements are in **1928.51(b)(2)** (employer provides seatbelt, ensures use while moving, ensures it is tightened). (b)(3) is spillage protection and (b)(4) is sharp-surface protection. The tightening line is (b)(2)(i)(C).
- **Appendix A to Subpart C (Employee Operating Instructions) is referenced by 1928.51(d), not 1928.57(a)(6).** 1928.57(a)(6) is the separate operating-instructions list for machine guarding (used in the PTO talk).
- Exemptions are 1928.51(b)(5)(i)-(iii).
