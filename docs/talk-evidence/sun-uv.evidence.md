**Scope note.** OSHA has no standard for sun or UV exposure for outdoor workers; no osha.gov sun-safety page was found by search. The talk uses NIOSH guidance only (kind "guidance"), plus one OSHA landscaping guidance line on shade. No statistics used. The existing `heat` talk covers water/rest/shade for heat illness; this talk is limited to skin and eyes.
