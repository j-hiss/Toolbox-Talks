# loading-ergonomics evidence

**OSHA has no ergonomics standard.** OSHA may address these hazards under the General Duty Clause, OSH Act Sec. 5(a)(1). All other lines are OSHA/NIOSH guidance (kind "guidance").

Sources fetched 2026-10-08:
- INT = OSHA Standard Interpretation, 2024-03-18, https://www.osha.gov/laws-regs/standardinterpretations/2024-03-18
- WH = OSHA Warehousing: Hazards and Solutions, https://www.osha.gov/warehousing/hazards-solutions (section "Ergonomics and Musculoskeletal Disorders")
- N = NIOSH Pub. 2007-131, Ergonomic Guidelines for Manual Material Handling, https://www.cdc.gov/niosh/docs/2007-131/pdfs/2007-131.pdf (landing: https://www.cdc.gov/niosh/publications/numbered/2007-131.html). Page numbers are from printed page footers as reported by the fetch tool; pp. 18-19 were flagged as approximate.
- The osha.gov/ergonomics topic page would not load (permission/provenance error); INT is used instead for the "no standard" line.
