# ppe-donning evidence

Overlap: the "ppe" talk is general PPE; "airborne-infection" and "hazardous-drugs" cover what to wear. This talk covers only the order for putting on and taking off. The order itself is CDC guidance (poster CS250672-E, hosted on cdc.gov), not an OSHA rule; the talk names it as CDC's. 1910.132(f) requires training on donning/doffing but sets no order.
