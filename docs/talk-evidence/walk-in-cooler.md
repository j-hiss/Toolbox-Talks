# walk-in-cooler evidence

Guidance page: OSHA Young Worker Safety in Restaurants eTool, Delivery/Storage, https://www.osha.gov/etools/young-workers-restaurant-safety/delivery ("eTool Delivery"). There is no OSHA standard that names walk-in coolers. The inside-release line is OSHA guidance; 1910.36(d)(1) covers "exit route doors" and was not cited because a walk-in door is not clearly an exit route door. 1910.37 is cited on the eTool page only for keeping exits/aisles clear, which is not walk-in specific, so it was not used. OSHA's cold-stress pages failed to load, so cold content is limited to the eTool.
