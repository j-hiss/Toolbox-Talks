151 = OSHA 1910.151(c) (https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.151).
133 = OSHA 1910.133(a)(1) (https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.133).
eTool-E = OSHA Powered Industrial Trucks eTool, Power Sources: Electric (https://www.osha.gov/etools/powered-industrial-trucks/types-fundamentals/power-sources/electrical).
INT = OSHA interpretation 2013-03-04 (https://www.osha.gov/laws-regs/standardinterpretations/2013-03-04).
NPG = NIOSH Pocket Guide, sulfuric acid (https://www.cdc.gov/niosh/npg/npgd0577.html).

No OSHA standard covers vehicle (automotive/truck) battery service. 1910.178(g) is forklift-only and is NOT cited.
The only OSHA guidance on lead-acid battery hazards found is the forklift eTool. The talk uses only its general
battery-chemistry and handling lines (acid, hydrogen, sparks, jewelry, PPE, flushing), names it as "OSHA's guidance",
and drops anything forklift-specific (designated charging areas, hoists, truck positioning). Reviewer: confirm this use
of forklift guidance for vehicle batteries is acceptable; if not, the "No sparks" and PPE-list lines need another source.
