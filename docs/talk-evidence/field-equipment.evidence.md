# Evidence: field-equipment

Scope note: the existing "pto" talk already covers PTO shaft guarding, the master shield, the (a)(6) operating instructions, riders, loose clothing and annual instruction. This talk narrows to augers and other field/farmstead equipment: (b)(2) power transmission parts, (b)(3)/(c)(3) functional components, (c)(3)(iii) portable grain auger guards, (c)(5) electrical lockout, plus unplugging. Shutdown and "everyone clear" lines repeat (a)(6) briefly because the assignment asked for them.

Access note: www.osha.gov standardnumber pages could not be fetched in this session (WebFetch permission/provenance refusal; curl blocked). 1928.57 was read from the eCFR copy (https://www.ecfr.gov/current/title-29/subtitle-B/chapter-XVII/part-1928/subpart-D/section-1928.57), which the checker brief accepts; the sources list keeps the osha.gov URL. The WebFetch tool returns summaries with short quotes, not full verbatim text, so "exact" below means the quoted fragment was returned verbatim.

Paragraph corrections to the assignment: the source hint "1928.57" is right. Specifics: guarding of functional components is (b)(3) (field) and (c)(3)(i) (farmstead); portable grain auger guard dimensions are (c)(3)(iii)(A)-(B); electrical lockout means are (c)(5)(i)(A)-(B); the pre-1976 exemption is (a)(3) (not (a)(4), which is the effective date); "guarded by location" is defined in (a)(9). There is no (c)(6).
