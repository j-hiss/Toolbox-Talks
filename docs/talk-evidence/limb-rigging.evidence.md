# limb-rigging — evidence

Pages fetched 2026-10-08 with WebFetch (summaries plus short exact quotes).
HB3731 = https://www.osha.gov/sites/default/files/publications/OSHAHB3731.pdf (HB-3731-2014) · 3752 = https://www.osha.gov/sites/default/files/publications/OSHA3752.pdf · 3940 = https://www.osha.gov/sites/default/files/publications/OSHA3940.pdf (OSHA 3940-02, 2018) · MEMO = https://www.osha.gov/memos/2021-06-30/inspection-guidance-for-tree-care-and-tree-removal-operations · 132 = 1910.132

**Scope note.** OSHA has no tree-care or arborist-rigging standard (https://www.osha.gov/tree-care/standards: tree care follows the general industry standards). No fetched OSHA page gives rigging-gear specifics (rope ratings, blocks, friction devices); 3940 and the tree-care hazards page were checked and say nothing on rigging gear. This talk stays with HB3731/3752/3940 guidance plus 1910.132.

**Overlap check.** tree-felling already covers drop zones (cones/tape, qualified workers only, stand clear / all clear) and retreat paths. This talk is narrowed to the rigging decision, the tree's ability to take rigging forces, gear inspection, not using the bucket as a crane, and the communication system HB3731 ties to rigging. The drop zone gets one line.
