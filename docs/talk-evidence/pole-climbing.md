# pole-climbing — evidence

Pages fetched 2026-10-07 with WebFetch: osha.gov 1910.269 (page 1: (a), (g)), 1910.269 page 2 (`1910.269_2`: (q)(1)), 1926.954, 1926.964, 1910.269 Appendix D.

Paragraph corrections to the assignment: 1910.269(q)(1)(i) is correct for "elevated structures"; its construction twin is 1926.964(a)(2) (not (a)(1)). In 1926.954 the poles/towers fall protection rule is (b)(3)(iii)(B), climbing/changing location (b)(3)(iii)(C), daily inspection (b)(3)(i), free fall (b)(3)(iv), anchorages (b)(3)(v), snaphooks (b)(3)(vi). In 1910.269 the same rules are (g)(2)(iv)(A) (inspection), (g)(2)(iv)(C)(2) (more than 4 ft), (g)(2)(iv)(C)(3) (climbing), (g)(2)(iv)(D) (free fall). Proficiency training: 1910.269(a)(2)(viii) / 1926.950(b)(7), via Note 2.
