**Scope note.** OSHA has no general-industry, construction or agriculture standard for hitching utility trailers or loading equipment onto ramps (the OSHA landscaping hazards page lists only "Vehicle Accidents Hauling Equipment" / "Train and certify drivers" and a trailer-hoist resource; the riding mowers page names loading ramps as a roll-over location). So the talk rests on NIOSH/state FACE case findings and recommendations (framed as case findings, kind "guidance"), the OSHA riding mowers guidance page, and DOT/FMCSA cargo securement (49 CFR 393), named as DOT and limited to commercial motor vehicles on public roads. DOT coupling/safety-chain rules (393.70) were not used: their scope (full trailers, CMV definitions) is too conditional to state plainly, and the page was not fetched. 97CA011 is a California FACE report (NIOSH-funded state program); cited by its CDC Stacks copy (the URL that was fetched).
