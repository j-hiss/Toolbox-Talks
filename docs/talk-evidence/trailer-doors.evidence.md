# trailer-doors evidence

**No OSHA standard covers opening trailer doors.** Every line is from guidance (kind "guidance"). Guidance is thin, so the talk is short (232 English words, above the 200-word minimum).

Sources fetched 2026-10-08:
- 3944 = OSHA 3944-04 (2018), "Safety Practices Once Tractor Trailer Drivers Arrive at a Destination", https://www.osha.gov/sites/default/files/publications/OSHA3944.pdf
- FACE = Washington State FACE report 71-207-2021, "Truck Driver Crushed by Cardboard Bale". Landing page https://stacks.cdc.gov/view/cdc/229106 (FACE series, NIOSH collection, "description provided by NIOSH", cooperative-agreement funded); full text https://seguridad.lni.wa.gov/safety-health/safety-research/files/2021/71_207_2021_TruckDriverCrushedByCardboardBale.pdf. Framed in the talk as a case finding, not a rule.
- TIP = Washington State SHARP Program / TIRES Project tip sheet "Protect yourself from falling objects" (2008), in the CDC Stacks NIOSH collection, https://stacks.cdc.gov/view/cdc/200358 and .../cdc_200358_DS1.pdf. **Reviewer note:** this is a state (WA L&I) publication, not an OSHA/NIOSH-authored one. It only supports "don't try to catch it" and the list of securing aids (cargo bar, webbing, shrink-wrap, side wall). If the reviewer won't accept it, drop those two phrases; everything else stands on 3944 and FACE.
