# hazardous-drugs evidence

OSHA has no standard written only for hazardous drugs. OSHA's Hazardous Drugs Standards page says hazardous drugs are addressed in 1910.1200 (Hazard Communication) and 1910.1450 (laboratories), and lists 1910.1020 records access. Glove, gown, eye/face, respirator, spill and waste practices come from OSHA's guidance "Controlling Occupational Exposure to Hazardous Drugs" (osha.gov/hazardous-drugs/controlling-occex), which cites NIOSH and ASHP. These are recommendations, so the talk words them as recommendations or practical steps, not as OSHA rules.
