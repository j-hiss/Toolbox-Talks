# rope-descent evidence

Rope descent systems in general industry: 29 CFR 1910.27(b), fetched from the osha.gov standardnumber page on 2026-10-08. Paragraph (b) is written as employer duties ("The employer must ensure..."); the building owner's duty is (b)(1)(i). Definition of rope descent system from 1910.21(b) ("Rope descent systems do not include industrial rope access systems").

Notes and corrections:
- 1910.27(b) itself is a heading. Anchorages are (b)(1)(i)-(iii); (b)(1)(iii) set the November 20, 2017 implementation date (not used in the talk). There is no (b)(1)(iv).
- Use rules are (b)(2)(i)-(xiii) (13 items, not 12). Weather is (b)(2)(xi); tools (b)(2)(xii); heat/chemicals (b)(2)(xiii).
- Wording of (b)(2)(i) exception: the fetch summarized it as "other access is not feasible or poses a greater hazard". A reviewer should confirm the exact clause; the talk keeps it general ("isn't possible or is more dangerous").
- No staged numbers or statistics were used. Industrial rope access is excluded by the definition; the talk does not address it.
