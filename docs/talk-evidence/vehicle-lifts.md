# vehicle-lifts evidence

**No OSHA standard.** OSHA's Nov. 19, 2014 interpretation letter states: "OSHA does not have any specific standards that
apply to a user of automotive lifts." Hazards fall under the General Duty Clause, Section 5(a)(1). The letter names
ANSI/ALI ALOIM as the industry consensus standard but OSHA does not enforce it directly; per the brief, ANSI content is
not used. Guidance is thin, so this is a short talk (about 250 words).

LOI = OSHA interpretation 2014-11-19 (https://www.osha.gov/laws-regs/standardinterpretations/2014-11-19).
FACE = California FACE report 03CA010, a state program run in cooperation with NIOSH, hosted by NIOSH
(https://www.cdc.gov/niosh/face/stateface/ca/03CA010.html). Reviewer: this is a NIOSH-hosted fatality report, not an
OSHA page; recommendations reference California's IIPP rule, which is state law, so no IIPP duty is stated in the talk.
IMIS = OSHA accident report detail id 553644 (https://www.osha.gov/ords/imis/accidentsearch.accident_detail?id=553644).

Dropped for lack of a source (important for reviewer): **"locks engaged before going under"** and **lift inspection
schedule** — no fetched OSHA or NIOSH page covers lift locks/latches or inspection intervals (the 2014 letter does not
address them; the FACE reports reviewed say "not addressed"). These live in ANSI/ALI ALOIM and lift manufacturers'
manuals, which the brief excludes as sources. "Only trained users" as a rule was also dropped: no federal rule says it;
the talk states the training facts from the two fatality cases instead. Also dropped: raise-slightly-and-check practice
(no fetched source).
