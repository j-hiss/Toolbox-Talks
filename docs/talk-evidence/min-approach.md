# min-approach — evidence

Pages fetched 2026-10-07 with WebFetch (summaries with short exact quotes). Pages: osha.gov 1910.269 (page 1 and page 2 `1910.269_2`), eCFR 1910.269 (for Table R-6, which the osha.gov page view truncated), 1926.960, 1910.333. "exact" = returned as an exact quote.

Paragraph-number corrections: the brief's "1926.960(c)" is right for MAD; the qualified-employee rule in 1926.960 is (b)(1), not (a). Table R-6 in 1910.269 is titled "Alternative Minimum Approach Distances for Voltages of 72.5 kV and Less"; its construction twin is 1926.960 Table V-5. The required MAD is computed from Table R-3 (1926: Table V-2); R-6/V-5 is an alternative.
