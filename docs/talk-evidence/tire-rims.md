# tire-rims evidence

All from OSHA 1910.177, https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.177, fetched 2026-10-07.

Scope note: 1910.177(a)(1) covers large-vehicle rim wheels and excludes automobile tires and pickup/van wheels using automobile or "LT" tires. 1910.177(a)(2) excludes employers covered by parts 1918, 1926 and 1928 (longshoring, construction, agriculture). Industries "truck" and "auto" fit general industry; an auto shop that only does car/light-truck tires is outside this rule, which the talk says.

Paragraph mapping correction: the assignment's topics map to (f) = multi-piece procedures and (g) = single-piece procedures. (e) is component acceptability.
