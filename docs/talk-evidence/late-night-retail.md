# late-night-retail evidence

OSHA has no standard for workplace violence or robbery. OSHA 3153 says: "These recommendations are advisory in nature and informational in content" and it "neither creates new legal obligations nor alters existing obligations". So every line is guidance, worded as practice, not as an OSHA rule. Code field is "OSHA 3153 (guidance)" rather than a CFR section.
